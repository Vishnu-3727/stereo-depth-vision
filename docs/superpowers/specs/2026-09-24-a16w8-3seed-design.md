## 0 Hypothesis (frozen)

16-bit activations with 8-bit weights, whole graph quantized (no fp32 islands),
meet the criterion on all 3 E3 best checkpoints.

Grounds (recorded references, NOT re-claimed here):

- `stage_e_recipe/npu_quark/REPORT.md` Q2 (A16W8, full graph) CPU EPE 1.3683450
  on E3 seed-0 best — a 17x improvement over R0 all-int8 (5.25) and within
  striking distance of fp32 (1.186). The NPU compiler crashed (aiecompiler
  77-5379) so NPU EPE is unknown; the CPU result is the signal.
- `stage_e_recipe/int8_head_refinement.py` R2 (head+refinement fp32) CPU EPE
  1.291 / 1.291 / 1.291 on seeds 0/1/2 with residual +0.105 / +0.112 / +0.120 px
  — meets the inherited criterion (R_ACCEPT 0.50, RESID_MAX_PX 0.50 on all 3
  seeds). A16W8 keeps the whole graph quantized (no fp32 islands); if it meets
  the same criterion, it is a strictly stronger result (smaller model, no
  fp32 fallback surface).

What counts as "enough" is the frozen inherited threshold (§7), not an
author-set one.

## 2 Quantizer (frozen, identical to control except activation_type)

- Exact `stage_e_recipe/int8_control.py` `quantize()` procedure via
  `stage_e_recipe/int8_sensitivity.py` `quantize_with_excludes`, no deviations:
  `quantize_static`, `QuantFormat.QDQ`, **`activation_type=QInt16`** (signed
  16-bit), `weight_type=QInt8`, `per_channel=True`, default
  `op_types_to_quantize` (None), default calibrate method (MinMax), no
  pre-processing step (same omission as control and EXP-015 — like-for-like).
- **Why QInt16 not QUInt16**: activations in this graph include pre-activation
  values (before LeakyReLU) and residual additions that can be negative; QInt16
  preserves the sign bit. QUInt16 would clamp or misrepresent negative
  activations. The npu_quark run (Q2) used QInt16 for activations and QInt8
  for weights; we replicate that choice.
- Calibration data: first 32 scenes of `hailo_calib` split
  (`Kitti2015Stereo(... split="hailo_calib")`, `CALIB_N = 32`), identical
  `Reader` construction and `normalize()` preprocessing. `hailo_val` is never
  used for calibration.

## 3 Arms (frozen)

Per seed (3 seeds), produce by passing through to `quantize_with_excludes`:

- Arm **fp32** — the reused §1 ONNX, scored directly (no quantization).
- Arm **R0** — all-int8 baseline: `nodes_to_exclude=None`, exact §2 procedure

- Arm **A16** — A16W8 whole graph (PRIMARY): `nodes_to_exclude=None`, §2
  procedure with `activation_type=QInt16`, `weight_type=QInt8`.
- Total configs: 3 seeds × 3 arms = 9 scorings.
- Each quantized artifact is written under a new sibling output dir only
  (§10), never beside existing bundles. Its `.onnx` is DELETED immediately
  after scoring; sha256 recorded before deletion (same rule as the
  precedent).

## 5 Baseline reproduction gate (STOP rule, frozen)

- Before ranking any A16 arm row, the script re-scores reference points per
  seed on the 40-scene contract and checks:
  - `|EPE_fp32_measured − <seed fp32 reference from §1>| <= 1e-6` px, and
  - `|EPE_R0_measured (QInt8 act) − <seed int8 reference from §1>| <= 1e-6` px,
    and
  - all guards `contract_match == true`.
- If ANY check fails on ANY seed: STOP. Write what was measured, do not
  proceed to A16 arms, do not reinterpret. (Tolerance rationale: same
  machine, same deterministic CPU procedure — bit-near reproducibility
  expected; 1e-6 absorbs fp32 reduction-order noise only.)

## 6 Memory guard (frozen)

- Each quantization runs in a **child process**. Parent polls free RAM every
  2 s; if free RAM < 2.0 GB, parent kills the child, records the event, and
  does not score that arm for that seed.
- If the guard trips at 32 calibration scenes: STOP, amend this spec
  (committed) to reduce `CALIB_N` to 16, then 8, then retry. The amended
  spec must be committed before any retry measurement.

- Residuals: `resid_A16,seed = EPE_A16 − EPE_fp32`.
- Report one table (3 rows, one per seed) with EPE (fp32 / R0 / A16),
