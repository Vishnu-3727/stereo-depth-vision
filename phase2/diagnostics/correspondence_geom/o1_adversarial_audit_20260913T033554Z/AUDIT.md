# 2. FORMAL INTERVENTION DEFINITION

**DERIVED.** Frozen quantities: `V[k,w] = Lf[w+k] − Rf[w]`, shape
`(1, 32, D=12, 17, 71)`; aggregation
`A = Conv3d(32→1,3³) ∘ (LeakyReLU ∘ Conv3d(32→32,3³))⁴`, zero padding on all
three of `(k,y,w)`; readout `R`: bilinear upsample on `(y,w)`, z-score across
`k`, `softmax(−z)`, soft-argmin with weights `k = 0…11`.

Let `π` be a bijection of `{0,…,11}` and `(V∘π)[k] := V[π(k)]`.

The proposal, as written, is the **position** permutation applied before
aggregation, read out in place. Denote it **P1**:

```
P1 :   m_π  =  R( A( V ∘ π ) )
```

A second variant, which the proposal does **not** specify but which §4.9 of the
brief demands be decided, applies `π⁻¹` to the aggregated cost before readout:

```
P2 :   m_π  =  R( A( V ∘ π ) ∘ π⁻¹ )
```

Statistic as proposed:
`E_orig = |m − τ|`, `E_perm = |m_π − τ|`, `Δ = E_perm − E_orig`.

**P1 and P2 are different experiments testing different hypotheses.** The
proposal is silent on which is meant. §5 shows they have opposite diagnostic
content.

# 3. SYMMETRY-GROUP ANALYSIS

## 3.1 The inherited group

**Authoritative (GEOM-002).** With `Rf[w] = Lf[w+τ]`, substituting `u = w+τ`,
`d = k−τ` gives `V(k,w) = F(k−τ, w+τ)`; verified exactly, residual `0.0` over 60
checks. `G` = the group generated by `(k,w) ↦ (k−s, w+s)`.

## 3.2 Where each stage sits with respect to a candidate-axis permutation

**DERIVED, and each row independently confirmed numerically.**

| stage | acts on | commutes with `π` on `k`? |
|---|---|---|
| cost-volume construction | builds the `k` axis | n/a — `π` is applied after |
| **bilinear upsample** | `(y,w)` only | **YES, exactly.** Linear and untouched by `k` |
| **z-score across `k`** | symmetric function of the 12 values | **YES, exactly** — `z(c∘π) = z(c)∘π`, **MEASURED** max residual `1.8e-06` |
| **softmax(−z)** | pointwise on `z` | **YES, exactly** — **MEASURED** max residual `1.2e-07` |
| **soft-argmin** | weights by absolute index `k` | **NO** — this is where `π` becomes visible |
| **aggregation `A`** | 3-wide conv over `k`, zero-padded | **NO** in general; **YES exactly** for any pointwise-in-`k` operator |

## 3.3 The exact readout identity

**DERIVED.** Because `z` and `softmax` are exactly equivariant,

```
m(c ∘ π)  =  Σ_k  k · p(π(k))  =  Σ_j  π⁻¹(j) · p(j)  =  E_{j∼p}[ π⁻¹(j) ]
```

where `p = softmax(−z(c))` is the **original** weight distribution. So under P1
the readout does not distort anything — **it relabels the soft-argmin weights by
`π⁻¹`**. Two consequences, both load-bearing:

1. **Any** operator whose weights `p` follow the content — corresponding or not —
   has its output moved by `π⁻¹`. That is the whole of `Δ_P1` for pointwise
   operators.
2. Because `p` is a probability distribution, `m_π` is an **expectation** of
   `π⁻¹`, pulled toward `mean(π⁻¹) = 5.5` whenever `p` is not sharp. This is the
   source of the artifacts in §6.5 and §8.2.

## 3.4 The z-score removes gain, not shape

**MEASURED (`o1_cex3.py`).** Scaling the aggregated cost by `g ∈ {0.25 … 64}`
changes `E_orig`, `Δ_P1` and the point-prediction error **not at all** (identical
to the printed precision) — the z-score divides it out.

**This corrects a concern that has been raised loosely as "sharpness".** Global
gain is **not** a confound. What remains a confound is the **shape** of the
standardised profile — its peakedness relative to its own spread. **MEASURED:**
median max-softmax-probability is `0.5934` for the match readout and `0.2885` for
random Conv3d aggregation (uniform would be `0.0833`). Peakedness of shape is a
real nuisance dimension, unrelated to geometry.

## 5.1 Labels versus positions — they are not equivalent

**DERIVED.**

- **Permuting labels** (reorder the soft-argmin weights, leave the tensor alone):
  the aggregation is untouched; `m → Σ π(k) p(k)`. Tests the readout only.
  Carries no information about the aggregation.
- **Permuting positions** (the proposal): changes what the `k`-convolution sees
  as neighbours **and** relabels the readout weights. **Two effects at once.**
- **Positions with `π⁻¹` restored before readout (P2):** cancels the readout
  relabelling and leaves **only** the neighbourhood effect.

**P1 confounds two distinct things.** That is why it fires on a translation.

## 5.2 P1 and P2 test different hypotheses — measured

```
mechanism                       Delta_P1 (reverse)   Delta_P2 (reverse)
genuine match / pointwise            +2.554               +0.000
atypical-slice latch                 +2.702               -0.000
adjacency-only, no matching          +0.101               -3.299
absolute-index bias                  +0.000               +0.000
random Conv3d aggregation            -0.090               +0.471
```

**MEASURED.** `Δ_P2 = 0.000` **exactly** for every pointwise operator, because
`A(V∘π)∘π⁻¹ = A(V)` identically. So:

> **P1 measures "does the output index follow the content".**
> **P2 measures "does the aggregation use candidate-axis neighbourhood
> structure".**

Neither measures correspondence. P2 is the cleaner and more specific of the two —
and its claim is weaker still (§10).

## 5.3 What a genuine correspondence mechanism must do — and whether it can be seen

**DERIVED.** Matched content sits at position `π⁻¹(τ)` after permutation, so a
mechanism that reports the index of the matched slice must output exactly
`π⁻¹(τ)`. This **point prediction** is far more constraining than `Δ > 0`.

**MEASURED — but it is smeared by the soft readout even for an ideal matcher:**

```
random  pi:  predicted pi^-1(tau) = [11, 1, 2, 5, 0, 4]
             observed  m_pi        = [8.70, 2.88, 3.44, 5.19, 2.31, 4.63]
             mean |obs - pred|     = 1.459      (a HARD matcher would give 0)
reverse pi:  mean |obs - pred|     = 0.890
```

The soft-argmin averages `π⁻¹` under a non-degenerate `p`, so even a perfect
matcher misses its own prediction by ~1–1.5 candidates. **The point-prediction
test is degraded by the frozen readout and its achievable fidelity for the
trained model is UNKNOWN without loading it** — which this audit does not do.

# 6. S8 STATISTIC ANALYSIS

## 6.1 Symmetry — invariant under `G`?

**No — and that is not the reassurance it looks like.** **MEASURED:** cyclic
translations, which *are* elements of `G`, give `Δ_P1 = +0.507, +1.098, +1.687`.
S8 is non-invariant under `G` for a **trivial** reason: the soft-argmin weights
are pinned to absolute positions, so *any* re-indexing moves `m`.

> Non-invariance under `G` is **necessary, not sufficient**. S8 satisfies the
> prior audit's screening criterion and is still not identifying.

**Is there another symmetry that makes S8 non-identifying?** Yes, and it is the
one that matters: **S8 is invariant under the choice of mechanism within the
class of pointwise-in-`k` operators.** For every such operator,
`m_π = E_{j∼p}[π⁻¹(j)]` with `p` the operator's own weights, so S8 depends on the
operator *only through `p`* — and `p` peaked at `τ` is achieved by matching, by
atypical-slice latching, and by anything else that prefers the zero slice. That
is the exact statement of NOT IDENTIFIABLE.

## 6.2 Absolute-index dependence

**S8 measures whether the output index follows content, not whether the axis is
used geometrically.** `M_pos` (`Δ_P1 = 0.000`) shows S8 excludes pure index bias
— a genuine but narrow exclusion. Everything content-driven is lumped together.

## 6.3 Can a sharper-but-wrong model give positive `Δ`?

**Yes. MEASURED:** `M_lag+3` — a confidently wrong matcher — gives
`Δ_P1 = +0.683 … +1.290` across permutations while `E_orig = 2.662`.
**`Δ` alone admits it.** Only the absolute-error clause
(`E_orig ≤ threshold`) rejects it. Any design that reports `Δ` without that
clause is broken.

Note the refinement from §3.4: *global gain* is removed by the z-score, so the
confound is profile **shape peakedness**, not scale.

## 6.4 Is the sign of `Δ` uniquely interpretable?

**No. MEASURED.** For the *genuine* mechanism with one fixed random `π`:

```
tau :     1      2      3      4      5      6
Delta : +5.855 +4.155 +1.795 -0.559 +1.174 +1.917
```

The sign **flips** at `τ = 4` for the mechanism the design is meant to detect.
The sign of `Δ` is determined by whether `π⁻¹(τ)` happens to land nearer to or
further from `τ` than `m` did — a property of the **arbitrary permutation**, not
of the model. A per-`τ` or per-`π` sign rule would be reading noise.

## 6.5 Magnitude — is `Δ = 1.0` candidate meaningful?

**REJECTED.** Three independent reasons, all **MEASURED** or **DERIVED**:

1. **The scale is set by `π` and `τ`, not by the mechanism.** Observed per-`τ`
   range for one `π` and one mechanism: `−0.559 … +5.855`. A threshold of 1.0
   sits inside the noise induced by choosing `π`.
2. **There is a systematic `τ` artifact.** `m_π = E[π⁻¹]` is pulled toward
   `5.5`, so a fully disrupted model looks *least* disrupted at `τ ≈ 5–6` — where
   `|5.5 − τ|` is smallest. **The design's own effect is anti-correlated with `τ`
   for reasons that have nothing to do with geometry.**
3. **The proposed quantisation rationale does not apply.** 1.0 candidate = 16 px
   was justified as "below this is readout smoothing". But the z-score removes
   gain (§3.4) and the smearing that actually limits resolution is
   `E[π⁻¹]` averaging — **MEASURED** at `0.89–1.46` candidates *for an ideal
   matcher*. The proposed threshold is the **same size as the method's own
   irreducible blur**.

**No threshold on `Δ` can be derived from the design as specified.** A defensible
threshold would have to be stated relative to a `π`-ensemble distribution, which
the proposal does not define.

# 9. POWER / GATE ANALYSIS

**DERIVED.** A max-over-null rule is impermissible for the reason in §8.9. That
argument requires no data and is independent of GEOM-002's numbers.

**The deeper problem is not power — it is that power is being spent on a
statistic whose positive result is ambiguous.** With `Δ_P1` in the `+2` range for
the target mechanism and a random-weight floor at `+0.015`, the design would very
likely return a confident positive. **MEASURED evidence that this positive would
be uninterpretable:** the same `+2`-range positive is returned by
atypical-slice latching (`+2.318`) and, at `+1.687`, by a transformation that
never left the failed symmetry group.

> **This is precisely the failure the successor was commissioned to prevent:
> "trained result looks impressive, then we discover the statistic was
> architecturally available."** O1/S8 would produce an impressive number.

# 11. REMAINING METHODOLOGICAL DEFECTS

1. **Under-specification (brief §4.1, §4.2, §4.3, §4.9).** `π` is undefined;
   fixed-vs-random undefined; single-vs-ensemble undefined; and **P1 vs P2 is
   undefined although they test different hypotheses** (§5.2). On its own this
   would be verdict **D**; it is subsumed by **C** because the collapse in §7 is
   structural and holds for every way of filling those blanks.
2. **Designer contamination (brief §11).** O1/S8 is a **post-hoc candidate**.
   Prior identification of candidate-axis permutation in an earlier diagnostic
   note is **not** independent preregistration, and must not be cited as
   validation. Mathematically justified ≠ preregistered before observing
   GEOM-002. This audit finds the mathematical justification **insufficient**
   regardless of its provenance, so the contamination question is not load-bearing
   for the verdict — but it would have been had the verdict gone the other way.
3. **Same three checkpoints (brief §12).** Three seeds of one recipe, already
   inspected repeatedly. **What is lost, precisely:** (i) no inference about the
   *training procedure* is available — `n = 1` recipe, and three seeds bound
   seed-noise only; (ii) agreement across the three is **not** replication, since
   they share data, schedule, architecture and initialisation family; (iii)
   repeated inspection means any threshold tuned to them is fitted to them.
   **They must never be described as independent replications of training.** A
   claim that survives all three is a claim about *these three artifacts*.
4. **The synthetic degeneracy is load-bearing and unnatural.** `V[τ] ≡ 0`
   exactly. Real stereo never presents an exactly-zero matched slice. Mechanism
   **A8** exploits exactly this. Any successor on synthetic translated self-pairs
   inherits it.
5. **The frozen readout blurs the only sharp prediction available.** `m_π`
   misses `π⁻¹(τ)` by `0.89–1.46` candidates even for an ideal matcher
   (**MEASURED**). The design's resolution is comparable to its own proposed
   threshold.
6. **`Δ`'s sign is not interpretable** (§6.4) and its scale is set by `π`
   (§6.5). Both are properties of the statistic, not of noise, and neither is
   fixable by increasing sample size.

# 13. FINAL DECISION

```
C — NOT IDENTIFIABLE
```

A plausible non-correspondence mechanism (**A8**, atypical-slice latching)
reproduces the O1/S8 signature under every permutation tested, and the statistic
additionally fires on a transformation that never leaves the symmetry group that
destroyed GEOM-002. The control/statistic pair cannot distinguish the hypotheses
it was proposed to distinguish.

**The successor path as proposed is terminated.**

# 14. CONDITIONS UNDER WHICH ANY SUCCESSOR WOULD BE JUSTIFIED

Not a design. The minimum any future proposal must clear before it is worth
auditing again:

1. **Escape the degeneracy, not just the group.** The decisive defect is not the
   translation symmetry — it is that on a translated self-pair the matched slice
   is **exactly zero**, so "find the match" and "find the weird slice" are the
   same task. Any successor on this construction inherits **A8**. A proposal must
   either break that degeneracy (matched slice small but *not* exactly zero, with
   a stated, derived residual) or leave the construction.
2. **Produce a point prediction, not a direction.** `Δ > 0` is satisfied by too
   much. A defensible design predicts *where* the output goes
   (`m_π = π⁻¹(τ)`) across an ensemble of `π`, and demonstrates — before loading
   any weight — that its irreducible blur is well below the predicted
   displacement. **MEASURED here: the frozen readout's blur is `0.89–1.46`
   candidates**, which is the bar to beat.
3. **Execute the counterexample suite at design time.** `HS-CEX`. Every defect in
   this audit was found by running six toy mechanisms for a few seconds with no
   checkpoint. Two experiments have now been lost to defects that were derivable
   in advance; this is the cheapest possible insurance.
4. **State the claim in the vocabulary the design can support.** If the design
   can only reach "uses candidate neighbourhoods", it must say so — and then
   answer whether that is worth measuring, given that the architecture is built
   from candidate-axis convolutions.
5. **Do not treat the three checkpoints as replications.** Any claim is a claim
   about those three artifacts.
6. **If 1 and 2 cannot both be met, stop.** Recording that the synthetic
   translated self-pair class is exhausted — for the stated, proven reason — is a
   real result. It is more valuable than an eleventh ceiling, and materially more
   honest than a confident `Δ = +2` whose interpretation this audit has already
   shown to be ambiguous.

# 15. WHAT THIS AUDIT ESTABLISHES

**MEASURED**

1. The z-score and softmax are exactly permutation-equivariant (`1.8e-06`,
   `1.2e-07`); the bilinear upsample commutes with `π` by construction.
2. `m(c∘π) = E_{j∼p}[π⁻¹(j)]` — under P1 the readout relabels the soft-argmin
   weights and nothing more.
3. A cyclic translation, an element of `G`, gives `Δ_P1 = +0.507 / +1.098 /
   +1.687`.
4. Atypical-slice latching reproduces the correspondence signature under every
   permutation tested (`E_orig` `0.816` vs `0.890`; `Δ_P1` `+2.2…+2.7` vs
   `+2.0…+2.6`).
5. Absolute-index bias gives `Δ_P1 = 0.000` exactly — the one alternative O1
   excludes.
6. `Δ_P2 = 0.000` exactly for every pointwise operator; large and negative for an
   adjacency-user.
7. `Δ`'s sign flips across `τ` for the target mechanism (`+5.855 … −0.559`).
8. The random-weight floor for `Δ_P1` is `+0.015`, and sits there because the
   standardised profile is weakly peaked (max prob `0.2885` vs `0.5934` for a
   matcher), not because of geometric blindness.
9. The point prediction `m_π = π⁻¹(τ)` is missed by `0.89–1.46` candidates even
   by an ideal matcher.
10. The z-score removes global gain exactly: a `256×` cost rescaling changes
    nothing.

**DERIVED**

11. "Lag-0 preference" and "match readout" are the **same function** at this
    architecture; the cost volume already performs the matching.
12. `A(V∘π) = A(V)∘π` exactly for any pointwise-in-`k` operator — so no choice of
    `π` can separate two pointwise mechanisms.
13. P1 and P2 test different hypotheses; the proposal does not say which is meant.
14. Non-invariance under `G` is necessary but not sufficient for identification.
15. A max-over-null rule is forbidden, by `(1−p)^N`, independently of GEOM-002.

**NOT ESTABLISHED**

```
Level D — geometric correspondence :  NOT-DEMONSTRATED   (UNCHANGED)
evidence FOR / AGAINST correspondence : NONE, either direction
trained aggregation measured          : NEVER
```

**UNKNOWN**

- how peaked the trained model's standardised profile is — not measurable without
  loading it, which this audit does not do;
- whether the trained model uses candidate neighbourhoods at all (prior
  probability high, evidence zero);
- whether the point-prediction test would be feasible at the trained model's
  actual sharpness.
